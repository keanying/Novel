# 《凡骨问天》单集制作流程与定声包

> 有了定妆图和分镜剧本，下一步就是把每集做成成片。本文件写清楚**每一步怎么做**，以及每个角色的**声音设定（定声）**。

---

## 一、单集制作流程（8 步）

| 步骤 | 做什么 | 输入 | 产出 |
|---|---|---|---|
| 1 | **读分镜** | `剧本/第××集.md` | 确认每个镜头要用哪些定妆图、哪个场景 |
| 2 | **出首帧图** | 定妆图 ＋ 场景参考图 ＋ 分镜"生成提示词" | 每镜一张静态首帧图（9:16） |
| 3 | **图生视频** | 首帧图 ＋ 动作/运镜描述 | 每镜一段 5–6 秒视频 |
| 4 | **配音** | 分镜台词 ＋ 本文定声包 | 每句台词一条音频 |
| 5 | **音效与配乐** | 分镜"音效"列 | 环境声、听脉音效、配乐 |
| 6 | **剪辑** | 以上全部 | 按分镜顺序剪成约 90–110 秒 |
| 7 | **字幕与标识** | —— | 字幕、片尾取景卡、AI 生成标识 |
| 8 | **质检与导出** | 第九节清单 | 成片 ＋ 封面 ＋ 15 秒投流素材 |

### 为什么要先出首帧图，不直接文生视频
- 直接文生视频，人脸和场景每次都会变；
- 先用**定妆图做参考**生成首帧，人脸锁定后再让它动起来，跨镜头才不会变脸；
- 首帧图不满意可以低成本重做，视频生成更贵、更慢。

---

## 二、首帧图怎么出

**组装公式**（和 04 号文件第十三节一致）：

```
参考图：分镜里出现的每个角色的定妆图（最多 2–3 人）
提示词：锚点 ＋ 动作表情 ＋ 场景提示词（03 号文件）＋ 光线 ＋ 景别
        ＋ 通用画风词 ＋ 通用负面词
比例：9:16
```

**要点**：
1. **一镜最多 2 个主要人物的正脸**。三人以上的镜头，让多出来的人背对、侧对或虚化；
2. **群像不要一次生成**：先出主角首帧，背景人群用虚化或后期合成（04 号文件已经踩过这个坑）；
3. **告示、地图、牌匾上的文字不要靠 AI 生成**，容易乱码。生成空白纸面，剪辑时贴字；
4. **景别写进提示词**：特写、近景、中景、全景、大全景，模型能理解。

---

## 三、图生视频怎么做

视频提示词**只写"动"的部分**，人物外貌和场景已经在首帧图里了，不要重复。

**示例**（第 1 集第 7 镜，光柱冲天）：
> 首帧：石碑前的广场全景
> 视频提示词：一道湛蓝色光柱从石碑中冲天而起，云层被冲开一个圆洞，人群惊恐地仰头后退，衣袂被气浪吹动，镜头缓缓上升

### 运镜词表（视频模型能理解的说法）

| 分镜写法 | 视频提示词 |
|---|---|
| 推 / 慢推 | 镜头缓慢向前推进 |
| 拉 | 镜头缓慢向后拉远 |
| 摇 | 镜头水平横摇 |
| 跟 | 镜头跟随人物移动 |
| 升 / 航拍 | 镜头缓缓上升，俯瞰全景 |
| 仰 | 低角度仰拍 |
| 环绕 | 镜头围绕人物缓慢环绕 |
| 手持晃 | 手持摄影，轻微晃动 |
| 慢动作 | 慢动作，动作舒缓 |
| 静 | 固定镜头，画面静止，只有细微动作 |

### 实用技巧
- **时长**：每镜生成 6 秒，剪辑时取最好的 4–5 秒；
- **连续动作**（比如攀爬、追逐）：用上一镜的最后一帧当下一镜的首帧，动作才接得上；
- **说话镜头**：近景对白需要口型。可以用视频工具的对口型功能，也可以多用"画外音＋反应镜头"（听的人的表情），减少对口型的镜头数量；
- **一次不行就换首帧**：同一首帧反复生成视频效果都不好，通常是首帧构图有问题，回到第二步重做首帧更省。

## 四、特效做法

| 特效 | 推荐做法 | 说明 |
|---|---|---|
| **听脉**（全剧招牌） | **后期合成** | 视频模型做的涟漪每次都不一样。正确做法：先生成正常画面 → 剪辑软件里降低饱和度 → 叠加蓝色（灵气）或暗红色（心跳）的水波纹素材 → 音频抽空，只留被放大的那个声音。**做一个模板，全剧复用**，风格才统一 |
| 光柱、剑光、灵光 | 视频模型直接生成 | 写进视频提示词即可 |
| 叠化（灯儿→小禾等） | 剪辑软件交叉叠化 | 两个镜头各自生成，后期叠化 |
| 冷蓝回忆色调 | 剪辑软件调色 | 正常生成画面，后期统一加冷蓝滤镜和轻微柔焦 |
| 失聪 / 静音（第 16 集） | 音频处理 | 所有声音淡出，只留低频耳鸣，持续到集末 |

### 配音注意
- **主角心声**（分镜里标"心声"）：同一音色，后期加轻微混响，音量略低，区别于正常说话；
- **画外音**：正常配音，后期不加处理；
- **台词情绪**：分镜里括号标注的情绪（冷淡、咬牙、哭腔等）要写进配音工具的情绪参数或提示里。

## 六、音乐与音效

| 类型 | 建议 |
|---|---|
| **主题旋律** | 竹笛或芦笙的单旋律，配低频鼓点，悠远带一点苍凉，贵州山地的感觉。第一集定下来，片头、片尾和情感高潮反复使用 |
| **听脉音效** | 编钟般清亮的水滴声，配一次环境声抽空，**全剧统一用同一个音效** |
| **心跳** | 低沉的心跳声，空拍处直接静音（第 16 集） |
| **溶洞** | 水滴回声、远处暗河流水、低频嗡鸣 |
| **千灯寨** | 芦笙、鸡鸣、捣衣声、篝火噼啪 |
| **打斗** | 剑鸣、金属撞击、衣袂破风，不要血肉声 |

> 配乐和音效请使用**有商用授权**的素材库，或用 AI 音乐工具生成。不要直接用网上下载的影视原声。

## 七、剪辑、字幕与标识

- **画幅**：9:16 竖屏，1080×1920；
- **字幕**：白字黑边，放在画面下方三分之一处，**避开平台底部的按钮区**；
- **片头**：不放片头，第一秒就是钩子；
- **片尾**：最后 3 秒黑场，"下一集 · 标题"＋小字"取景：××景区"；
- **AI 生成标识**：按《人工智能生成合成内容标识办法》，在画面角落持续显示"AI 生成"字样，片尾再标注一次。**这是合规要求，必须加**；
- **封面**：每集选一张最有冲击力的首帧图，加上集数和一句钩子文案。

## 九、单集质检清单

- [ ] 每个角色的脸和定妆图一致（重点查：疤、泪痣、酒窝、胡子）
- [ ] 服装颜色符合 04 号文件"服装色标准"（剑宗服不能变成绿色）
- [ ] 画面里没有现代元素（护栏、电线、游客、彩色灯光）
- [ ] 没有乱码文字
- [ ] 手指、肢体没有畸形
- [ ] 每个角色的声音和定声一致
- [ ] 听脉特效用的是统一模板
- [ ] 前 3 秒有钩子，最后 5 秒有悬念
- [ ] 时长在 90–120 秒之间
- [ ] AI 生成标识已加
- [ ] 片尾取景卡已加

## 十、建议：先做第 1 集样片

1. 先做第 1 集，按本文流程完整走一遍；
2. 重点验证三件事：**跨镜头人脸是否一致、听脉特效模板是否好看、配音音色是否合适**；
3. 样片确认后，把首帧提示词、视频提示词、特效模板都固定下来，再批量做第 2–20 集。

**第 1 集预计用量**：20 个镜头 × 首帧 2–4 张 ＋ 视频 1–3 次，大约 40–80 张图和 20–60 段视频；配音约 15 句。
