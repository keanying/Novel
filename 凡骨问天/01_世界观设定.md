# 《凡骨问天》世界观设定

## 一、九渊界

- **地上**：群山、峰林、瀑布、花海，凡人王朝"南岭国"统治着城镇村落，都城叫**筑城**。
- **地下**：密如蛛网的溶洞和暗河。**灵气在地下暗河里流动**，就像血液在血管里流动。
- **九渊**：九个通往地下灵脉的大天坑，是灵气涌出地面的"泉眼"。

### 断脉之劫（三百年前）
地下主灵脉突然断流，九渊之中八渊枯竭。官方说法是"天地灵气衰退"。
**真相**：云巅宫开山祖师联合数位大能，在千里地宫封死了主灵脉，从此独占剩下的灵泉，修行成了宗门的特权。（第三季揭晓）

### 镇渊铃
云巅宫金顶上有一口古铜铃，和潜龙渊的封印相连。三百年来从没响过。**第 5 集许听澜觉醒听脉的那一刻，铃声无风自鸣。** 这就是云巅宫全力追捕一个凡人的原因。

## 二、修行规则

### 灵根
只有生来带灵根的人能把灵气引入体内。灵根分品阶和属性：

| 品阶 | 比例 | 说明 |
|---|---|---|
| 天灵根 | 约十万分之一 | 单一属性，修行一日千里 |
| 地灵根 | 约千分之一 | 两种属性 |
| 玄灵根 | 约百分之一 | 三种属性 |
| 黄灵根 | 较常见 | 四到五种属性，修行极慢 |
| 无灵根 | 大多数凡人 | 无法引气入体 |

属性：水、木、火、金、土。**许小禾是"天水灵根"**，三百年来云巅宫测出的第三例。

### 境界

| 境界 | 特征 | 剧中视觉 |
|---|---|---|
| 滴水境（一至九层） | 引气入体，体质强于常人 | 指尖有微弱水光 |
| 成溪境 | 灵气成流，可以御物 | 身周有细流般的光带 |
| 汇川境 | 可以御剑飞行 | 剑光拖出长尾 |
| 入渊境 | 神识入地，感应灵脉 | 眼中有幽蓝光 |
| 化海境 | 呼风唤雨，开宗立派 | 出手时天地变色 |
| 归墟境 | 传说，三百年无人达到 | —— |

### 移根术（全剧核心秘密）
- 用秘药让人昏迷，再用金针、阵法把灵根从丹田剥离，移植到另一个人身上。
- **养根**：孩子的灵根需要在灵泉里养一年才"成熟"，熟了再取，移植成功率最高。
- **被取根的人**：修为全废，元气大伤。成年修士还能活下去，孩子多半熬不过两三年。
- **接受者**：修为暴涨、寿命延长。云巅宫大长老宁鹤年靠这个活了三百年。

## 三、听脉（男主能力）

### 本质
听见灵气流动的"声音"。灵气越浓，声音越响；不同属性，音色不同：

| 属性 | 声音 | 画面表现 |
|---|---|---|
| 水 | 流水、滴水声 | 蓝色涟漪 |
| 木 | 树叶沙沙声 | 绿色细丝 |
| 火 | 柴火噼啪声 | 橙色火星 |
| 金 | 金属铮鸣 | 银白闪线 |
| 土 | 低沉鼓声 | 褐色波纹 |

**统一视觉语言**：每次听澜"听"的时候，画面降饱和、环境声消失，只剩他听见的声音，并以发光涟漪呈现。观众一看就知道"他在听"。

### 能听见什么
1. 灵脉、灵泉、灵石、灵药的位置；
2. 修士的修为高低（灵力流动的强弱）；
3. **心跳**：情绪起伏、是否说谎；
4. 阵法的节拍（每个阵都有节奏，节奏的空拍就是破绽）；
5. 剑气、法术袭来的方向。

### 代价
- 听得越远越细，耳朵、鼻子越会流血；
- 用力过度会暂时失聪，大约十二个时辰；
- 长期滥用会"被声音淹没"，分不清现实（第二季的危机）。

### 成长路线
| 阶段 | 季 | 能力 |
|---|---|---|
| 听 | 第一季 | 百步之内能听清，靠听破阵、辨谎、躲攻击 |
| 引 | 第二季 | 以声引脉，配合阵法调动地下灵气 |
| 借 | 第三季 | **借脉**：不需要灵根，直接借用大地灵脉的力量。证明凡骨也能问天 |

### 背夫习惯的伏笔
父亲教他"数着步子走，就不会怕"，所以他走盐道时总在数步子。这种对节奏的敏感，就是他能听脉的根基。

## 四、势力

### 七大宗门

| 宗门 | 驻地（取景） | 宗主 / 掌事 | 服饰主色 | 功法特点 | 与主线的关系 |
|---|---|---|---|---|---|
| **云巅宫** | 红云金顶（梵净山） | 宫主闭关多年；实际掌权的是大长老宁鹤年 | 白底金纹，云纹 | 御云、封印术、移根术 | 最终反派，灵根掠夺的源头 |
| **垂天剑宗** | 水帘洞天（黄果树瀑布） | 宗主萧寒江（中立，被蒙在鼓里） | 青白，水纹，青色剑穗 | 借瀑布之势练剑，剑意如水 | 女主原宗门；大师兄顾长风勾结云巅宫 |
| **丹霞谷** | 赤崖丹霞（赤水丹霞） | 谷主丹鸿（丹九之父） | 赤红、赭色 | 炼丹，以桫椤为灵植 | 第二季盟友 |
| **万峰阁** | 万峰林、八卦田 | 阁主陆千山 | 墨绿、灰，八卦纹 | 阵法，八卦田是护山大阵 | 男主后来的师门（季无咎是其弃徒） |
| **碧泉宫** | 七孔水府（荔波小七孔） | 宫主温若水 | 碧色 | 医术、水疗、解毒 | 第二季盟友，能修复受损的丹田 |
| **映山宗** | 杜鹃花海（百里杜鹃） | 宗主花映红 | 杜鹃红、紫 | 音律、幻术 | 立场摇摆，第二季关键 |
| **天工府** | 万钟洞府（织金洞） | 府主铁衡 | 黑褐色，铜饰 | 炼器，以石笋为炉 | 第二季出场，为男主打造"听脉器" |

### 凡间与江湖

| 势力 | 地点（取景） | 说明 |
|---|---|---|
| **盐帮** | 盐道（马岭河峡谷） | 背夫组织，盐比银贵，盐道上的规矩比王法还硬 |
| **千灯寨** | 西江千户苗寨夜景 + 肇兴侗寨鼓楼、风雨桥 | 山中村寨，热情善良，守护过往旅人；寨老德高望重 |
| **舞阳坊市** | 镇远古城 + 青龙洞 | 修士和凡人混居的中立集市，什么都能买到 |
| **散修** | 裂天峡（马岭河峡谷深处） | 没有宗门的修士，有好人也有亡命之徒 |
