# 《凡骨问天》场景库与古风化提示词

## 使用说明

- **场景标签**：分镜里的 `[青石镇·牌坊广场]` 对应本文件的场景提示词。
- **推荐流程**：先用景区实拍照片（自己拍摄或有授权的图片）做图生图，加古风化提示词，生成场景参考图并定稿；再用定稿图做图生视频。这样山形、水形最接近真实景区，观众认得出来。
- **图片版权**：网上下载的景区照片多数有版权，**请用自己拍的或有授权的图片**做参考。
- **统一去除**（加进负面词）：
  > 游客，现代人，栈道护栏，铁链扶手，缆车，电线杆，路灯，水泥路，柏油路，指示牌，广告牌，游船，快艇，彩色射灯，现代建筑，汽车，塑料，二维码
- **统一加入**（按需）：云海、雾气、飞檐古建、木栈道、灯笼、仙鹤、灵光粒子、御剑身影

## 第一季前十集场景

| 标签 | 取景 | 古风化提示词 | 推荐时段 / 天气 |
|---|---|---|---|
| `[青石镇·牌坊广场]` | 青岩古镇石牌坊、石板街 | 古朴山城小镇，青灰色石板广场，三座清代风格石牌坊，两侧木结构老屋和吊脚楼，屋檐挂旧灯笼，远处青山环抱，薄雾；广场中央立一块一人高的黑色测灵石碑，旁边搭起白色木台，挂白金色云纹幡旗 | 阴天柔光、晨雾 |
| `[青石镇·石板街]` | 青岩古镇老街 | 狭长的青石板古街，两侧木门板铺面和马头墙，石板被磨得发亮，屋檐下挂草鞋、竹篓、腊肉 | 清晨 |
| `[梯田]` | 加榜梯田 | 层层叠叠的山间梯田，水田如镜，倒映天空，田埂蜿蜒，远处木结构村寨冒着炊烟，山间云雾缭绕 | 黄昏、晨雾 |
| `[云舟]` | —— | 白玉与金饰打造的古代飞舟，船身刻云纹，白色船帆，船底托着云气，在云海上航行 | 云海、逆光 |
| `[盐道·峡谷栈道]` | 马岭河峡谷 | 幽深狭长的峡谷，两侧是数百米高的绝壁，崖壁上挂着细长的瀑布和垂藤；绝壁半腰凿出一条窄窄的古栈道，用木桩和石板铺成，只容一人通过，没有任何护栏，谷底激流翻滚 | 薄雾、阴天 |
| `[黑龙洞·入口]` | 织金洞入口 | 巨大的喀斯特溶洞洞口，像巨兽张开的嘴，洞口垂着藤蔓和蕨类，里面一片漆黑，洞口有一块风化的石碑，刻"黑龙洞"三个字 | 黄昏 |
| `[黑龙洞·洞厅]` | 织金洞洞厅（石笋、石柱、"银雨树"） | 极其宏大的地下溶洞大厅，高耸的石笋石柱林立，形态奇诡，钟乳石从洞顶垂下，地面湿滑，只有火把照亮一小圈，橙色火光映在钟乳石上，四周是深不见底的黑暗，水滴声回荡 | 火把光 |
| `[潜龙渊·暗河]` | 龙宫景区地下暗河 | 幽深的地下暗河，河水墨蓝冰冷，两侧是湿润的溶洞岩壁，洞顶低矮，钟乳石倒垂；水面上漂浮着点点幽蓝色微光，像星星落进了水里 | 幽蓝冷光 |
| `[潜龙渊·石台]` | 龙宫景区水溶洞 | 暗河边一块凸出水面的平坦石台，背后是巨大的龙鳞状岩壁，岩壁上的纹路隐隐透出幽蓝光芒，像沉睡的巨龙 | 幽蓝冷光 |
| `[潜龙渊·死路]` | 龙宫景区溶洞 | 暗河尽头的圆形洞室，四面都是光滑岩壁，头顶有一条极细的竖直裂缝，透下一缕月光，岩壁上垂着树根和藤蔓 | 月光一束 |
| `[天坑·坑口]` | 喀斯特天坑（可参考贵州各地天坑） | 巨大的圆形喀斯特天坑，坑壁垂直，长满藤蔓、蕨类和灌木，坑底森林茂密；夜晚，坑口上方是满月 | 夜、满月 |
| `[千灯寨·远景]` | 西江千户苗寨夜景 | 夜晚的山谷，层层叠叠的木结构吊脚楼沿山坡而建，千家万户亮起暖黄色灯火，像星河倾泻在山上，山脚有河流和风雨桥 | 夜（用暖黄烛火色，去掉彩色射灯） |
| `[云巅宫·金顶]` | 梵净山红云金顶 | 一座拔地而起的孤峰，巍峨的巨石之巅建着白玉金顶的仙宫，云海翻涌，金光万丈；峰顶悬挂一口巨大的青铜古铃（**不出现真实寺庙建筑**） | 日出、云海 |
| `[云巅宫·静室]` | —— | 白玉砌成的闭关静室，地面刻满金色阵纹，中央一个蒲团，四周烛火，帷幔低垂 | 烛光 |
| `[水帘洞天·大殿]` | 黄果树瀑布水帘洞 | 藏在巨大瀑布后面的天然石洞大殿，透过水帘能看到外面的光，水声轰鸣，殿内石柱上挂着青色剑旗，水雾弥漫（回忆戏用） | 夜、月光透过水帘 |

## 第 11–20 集新增场景

| 标签 | 取景 | 古风化提示词 | 推荐时段 / 天气 |
|---|---|---|---|
| `[千灯寨·寨门]` | 西江千户苗寨寨口 | 依山而建的木结构寨门，青瓦屋顶，门楣下挂两排红灯笼，门前是长长的青石台阶，两旁古枫树 | 夜，火把与灯笼光 |
| `[千灯寨·街巷]` | 西江千户苗寨石板巷 | 吊脚楼之间狭窄的青石板巷道，木板墙、木栏杆、屋檐低垂，檐下挂着玉米串和辣椒串 | 白天、晨雾 |
| `[千灯寨·晨景]` | 西江观景台视角 + 加榜梯田 | 清晨山谷中层层叠叠的木结构吊脚楼，屋顶青瓦湿润，炊烟袅袅，云雾在半山腰流动，山脚是如镜的梯田 | 清晨薄雾 |
| `[千灯寨·火塘]` | 吊脚楼室内 | 木结构吊脚楼室内，地面中央是方形火塘，铁三脚架上架着黑陶罐，房梁上挂着熏黑的腊肉，木板墙，一盏油灯，暖橙色火光 | 夜，火光 |
| `[千灯寨·古井]` | 寨中古井 | 青石砌成的圆形古井，井沿长满青苔，旁边放着木桶和葫芦瓢，井水清澈见底，周围是吊脚楼的木柱 | 白天 |
| `[千灯寨·鼓楼坪]` | 肇兴侗寨鼓楼 | 一座多层重檐的木结构鼓楼，层层叠叠的飞檐向上收拢成塔形，楼前是石板铺成的圆形坪地，中央燃着篝火 | 黄昏到夜，篝火 |
| `[风雨桥]` | 肇兴侗寨风雨桥 | 横跨小河的木结构廊桥，桥上是青瓦覆盖的长廊，中间和两头各有一座重檐亭阁，廊内有长凳和栏杆，桥下河水清浅 | 黄昏、夕阳 |
| `[云巅宫·灵泉院]` | —— | 白玉砌成的庭院，中央一方泛着幽蓝光芒的灵泉水池，池边白玉栏杆，四周白色回廊，几株白梅，雾气缭绕，冷清肃穆 | 冷色晨光 |
| `[舞阳河·夜航]` | 镇远古城·舞阳河 | 夜色中蜿蜒的河流，一艘乌篷小船缓缓前行，两岸是依山而建的古城木楼和石砌城墙，家家户户亮着暖黄色灯笼，倒映在河面上 | 夜（去掉现代桥梁和彩色灯光秀） |
| `[舞阳坊市·码头]` | 镇远古城码头 + 青龙洞古建筑群 | 古城石阶码头，拴着木船，码头墙上贴满悬赏告示；背后的悬崖上依山凿建着层层叠叠的古代楼阁，飞檐翘角，灯火通明，天空中偶有御剑飞过的光影 | 夜 |

> 镇远古城夜间有现代彩色灯光秀和水泥桥，生成时务必加进负面词："彩色射灯，霓虹灯，LED 灯带，现代桥梁"。
