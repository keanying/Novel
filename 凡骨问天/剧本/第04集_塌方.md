# 第 04 集《塌方》

| 项目 | 内容 |
|---|---|
| 时长 | 约 90 秒 |
| 场景 | `[黑龙洞·洞厅]` → 坠落 → 水下 |
| 出场 | 许听澜、老魏、石头、盐队背夫 |
| 本集任务 | 第一场动作戏；听澜舍身救人，立住"重情"的人设；坠入暗河 |
| 结尾钩子 | 冰冷的水里，那个声音再次响起："听澜……" |
