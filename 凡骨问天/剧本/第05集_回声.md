# 第 05 集《回声》

| 项目 | 内容 |
|---|---|
| 时长 | 约 100 秒 |
| 场景 | `[潜龙渊·暗河]` `[云巅宫·金顶]` `[云巅宫·静室]` |
| 出场 | 许听澜、宁鹤年（只露眼睛和手） |
| 本集任务 | **听脉觉醒**，确立听脉的视觉语言；镇渊铃响，大反派第一次出现；遇见女主的引子 |
| 结尾钩子 | 一片寂静中，传来另一个人的心跳 |

## 听脉视觉语言（全剧统一）
画面降饱和、环境声抽空 → 只剩一种被放大的声音 → 声音以幽蓝发光涟漪的形式在画面中扩散。

## 制作备注
- 第 8、9 镜是全剧最重要的视觉设定，后面每一次听脉都沿用这套风格，务必定稿。
- 心跳涟漪用暗红色，和灵气的蓝色区分开：**蓝色 = 灵气，红色 = 心跳**。
- 宁鹤年第一季前三卷只露眼睛、手和背影，保持神秘感。
