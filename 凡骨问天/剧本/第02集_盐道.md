# 第 02 集《盐道》

| 项目 | 内容 |
|---|---|
| 时长 | 约 95 秒 |
| 场景 | `[青石镇·石板街]`（老魏家门口）、`[盐道·峡谷栈道]`、`[黑龙洞·入口]` |
| 出场 | 许听澜、老魏、石头、盐队背夫 |
| 本集任务 | 交代父亲死在盐道；建立"数步子"的习惯；展示听澜的力量和沉稳；引出黑龙洞 |
| 结尾钩子 | 石头："那个洞……进去的人，没几个出来的。" |
