# 第 03 集《背夫的规矩》

| 项目 | 内容 |
|---|---|
| 时长 | 约 90 秒 |
| 场景 | `[黑龙洞·洞厅]` |
| 出场 | 许听澜、老魏、石头、盐队背夫 |
| 本集任务 | 营造溶洞的压迫感和神秘感；立下"三条规矩"；**只有听澜听见有人叫他**（听脉的伏笔） |
| 结尾钩子 | "别回头。"——头顶传来石头开裂的声音 |

## 制作备注
- 第 8、12 镜的呢喃是全剧主线伏笔（来自潜龙渊深处的脉龙），声音要空灵，像水声组成的人声。
- 第 15 镜新增伏笔：**父亲当年也听见过**。父亲之死不是意外，第二季揭晓。
