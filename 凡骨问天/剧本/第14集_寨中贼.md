# 第 14 集《寨中贼》

| 项目 | 内容 |
|---|---|
| 时长 | 约 100 秒 |
| 场景 | `[千灯寨·鼓楼坪]`（黄昏，篝火） |
| 出场 | 许听澜、沈青棠、杨灯儿、寨民（男、女）、外门弟子甲乙丙（乔装） |
| 本集任务 | 听脉"辨谎＋辨修为"的公开展示；男主第一次站出来当众揭穿；冲突爆发 |
| 结尾钩子 | 三把剑同时出鞘，指向寨民和灯儿 |
