# 《你和我们》故事大纲 v2：虚构家族叙事方案

> 类型：AI 生成历史短剧（教育向）｜单集 ≤ 3 分钟
> 时间：1839 — 2026｜总集数：**460 集**（上限 500，预留 40 集机动）
> 核心：**一个虚构的普通家庭，七代人，走过 187 年真实的历史**

---

## 一、为什么改版

v0.1 是"纪实拼盘"：每集讲一件真实大事，领袖和重大政治事件是画面中心，审核风险高。

v2 借鉴《大江大河》的**方法**：虚构的小人物当主角，真实的时代当背景，政策和事件从人物的生活里"渗进来"。这样做的好处：

- 主角是虚构人物，不存在"真实人物形象"和"历史人物言行"的审核问题；
- 重大事件不用正面拍，只拍它们对一个家庭的影响；
- 情感更连贯，观众追的是"这家人后来怎么样了"，完播率更高。

---

## 二、借鉴什么，避开什么

**著作权风险提醒**：创意和历史事实不受保护，但**具体的人物设置、人物关系和情节编排**受保护。琼瑶诉于正案（2014 年，北京三中院判《宫锁连城》侵权《梅花烙》）就是因为人物关系和情节结构相似。所以我们只借方法，不借结构。

| 维度 | 《大江大河》 | 《你和我们》 |
|---|---|---|
| 时间 | 1978 年以后的改革开放时期 | 1839—2026，横跨 187 年 |
| 结构 | 三位同代男主并行（国企技术员／村干部／个体户） | **一个家族七代人接力**，每部换一代主角 |
| 行业 | 化工、村办企业、商贸 | **印刷与文字**：木刻 → 铅字 → 激光照排 → 互联网 → AI |
| 地点 | 虚构的东海市、小雷家村 | 真实城市随家族迁徙：佛山 → 上海 → 重庆 → 上海／深圳 |
| 主角性别 | 男性为主 | 男女主交替，七代中三代以女性为主角 |
| 主题 | 个人奋斗与时代机遇 | **"人会走，字会留"**：知识与记忆的传承 |
| 叙事框架 | 线性叙事 | 2026 年的 18 岁少女回溯家族史，首尾呼应 |

**只借三个方法**：① 小人物＋大时代；② 行业细节必须真实；③ 正向基调，但不回避苦难。

## 三、核心设定

### 1. 传家之物：一块梨木刻版
1839 年，佛山刻字学徒程守拙看过虎门销烟以后，在一块梨木板上刻了六个字：**"人会走，字会留"**。这块刻版传了七代，每一部结尾交到下一代手里。它是全剧的线索、道具，也是片名的注脚。

### 2. 为什么选印刷行业
- 印刷技术的演变正好是中国近代化的缩影：木刻 → 西洋铅字（1843 年上海墨海书馆）→ 现代出版（1897 年商务印书馆）→ 简化字改铅字（1956）→ 激光照排"告别铅与火"（1987）→ 数字出版 → AI。
- **合规上最巧妙的一点**：程家世代以排字、印刷为生，所以每一件国家大事，都可以通过**他们亲手排出的标题、号外、告示**进入剧情。领袖不用出镜，事件不用重演，一张铅字排版的特写就交代了历史。

### 3. 叙事框架
- **开篇**：2026 年 6 月，程小满高考结束，回上海老宅收拾东西，在阁楼找到刻版，背面刻着"道光十九年 守拙刻"。爷爷程向东开始讲这个家的故事。
- **每部首尾**：回到 2026 年，小满的一小段反应，用她的声音说出固定句式："**那一年，我们……；今天，我……**"
- **终章**：小满决定用 AI 把家族的故事拍成短剧，片名叫《你和我们》，最后一个镜头转向观众，也就是"你"。

## 五、七部规划（共 460 集）

### 第一部《刻版》1839—1865｜程守拙｜35 集
佛山刻字铺。哥哥染上鸦片，家道中落 → 林则徐到广州，程记接下刻印禁烟告示的活（虚构情节）→ 守拙去虎门看销烟，回来刻下"人会走，字会留"→ 鸦片战争，在水师当兵的表兄战死虎门 → 三元里 → 《南京条约》传到佛山 → 广州反入城斗争（1849）→ 1854 年洪兵占佛山，清军镇压，程记被烧 → 英法联军占领广州（1858—1861）→ 好友被诱骗出洋当契约华工 → 1865 年送儿子立言去上海学西洋铅字

### 第二部《铅与火》1865—1897｜程立言｜40 集
上海。江南制造局翻译馆刻工，第一次刻"氧""氢"这些新造的化学元素名 → 1872 年《申报》创刊，进排字房学铅字 → 佛山同乡少年随首批留美幼童出洋，1881 年被撤回 → 丁戊奇荒，江南印《铁泪图》劝赈 → 马江海战的消息 → 甲午：立言亲手排出黄海海战、《马关条约》的新闻 → 1897 年排字工同事创办商务印书馆，立言送儿子知远进馆

### 第三部《新民》1897—1927｜程知远、程知微｜65 集
商务印书馆。知微进入上海第一所国人自办女学（1898）→ 1900 年东南互保下的上海 → 1903 年"苏报案" → 1905 年废科举，新式教科书供不应求 → 知微追随秋瑾的事迹，1911 年加入上海女子北伐队 → 民国成立、中华书局创办 → 《新青年》在上海印刷 → 1919 年"六三"上海工人罢工 → 1925 年五卅运动，知远在工人队伍里 → 1927 年上海工人武装起义

### 第四部《书比命长》1927—1949｜程望舒｜95 集（全剧最长）
九一八后的上海 → **1932 年 1 月 29 日，日军轰炸商务印书馆，东方图书馆随后被焚，知远为抢救藏书罹难（虚构）** → 商务复业，口号"为国难而牺牲，为文化而奋斗"（真实）→ 1937 年八一三淞沪抗战 → 望舒护送印刷机沿长江内迁：武汉 → 宜昌 → 重庆 → 重庆大轰炸、1941 年隧道惨案 → 为西南联大印教材，结识联大学生林静秋 → 豫湘桂溃败 → 1945 年胜利，排出"日本投降"号外 → 内战与金圆券恶性通胀 → 1949 年 5 月上海解放，士兵露宿街头

### 第五部《新纸》1949—1976｜程望舒（中年）、程向红（少年）｜70 集
抗美援朝，望舒的侄子参加志愿军 → 1956 年公私合营，程记并入国营印刷厂 → 1956 年汉字简化方案公布，全厂重铸铅字 → 1958 年汉语拼音 → 大跃进和三年困难时期（克制呈现）→ 1964 年原子弹爆炸，连夜印号外 → 1966 年起的十年动乱：藏书被烧，望舒把刻版藏进墙里（按 1981 年历史决议定性，以家庭遭遇为主，基调克制）→ 1968 年向红上山下乡 → 1976 年唐山地震，同年十月结束

### 第六部《春潮》1977—2000｜程向红、程向东｜80 集
1977 年冬，向红在知青点参加恢复后的第一次高考 → 1978 年重印中外名著，书店门口排长队 → 向红进出版社 → 王选团队的激光照排；1987 年第一张激光照排报纸问世，"告别铅与火"，向东所在的铅字车间开始萎缩 → 1990 年上交所开业 → 1992 年南方谈话，向东犹豫要不要下海 → 1997 年香港回归 → 1998 年向东下岗，在大学门口开复印打字店 → 1998 年洪水 → 2000 年复印店装上第一台联网电脑

### 第七部《光与屏》2001—2026｜程远、程小满｜75 集
2001 年申奥成功、加入世贸 → 2003 年非典，程远所在的大学封校 → 网络文学兴起，程远做电子书网站 → 2008 年：汶川地震程远去当志愿者；8 月小满出生 → 2010 年上海世博会 → 智能手机时代，程远创业失败又重来 → 2020 年新冠疫情，小满上网课，爷爷向东学会用手机 → 2021 年脱贫攻坚，退休的向红去乡村学校捐书 → 2024 年嫦娥六号月背采样 → 2026 年小满高考结束，找到刻版，用 AI 拍出《你和我们》→ 终章：镜头转向你

**合计：35 + 40 + 65 + 95 + 70 + 80 + 75 = 460 集**

## 八、合规处理方案（面向国内平台）

1. **领袖和高层人物**：不出现形象，不写台词。只通过家族亲手排的报纸标题、号外、广播声、告示来交代。
2. **真实非政治人物**（如张元济、王选、詹天佑）：最多作为背影或旁人口中的名字出现，不安排虚构对白。
3. **敏感时段**：
   - 大跃进、三年困难时期、十年动乱：按 1981 年《关于建国以来党的若干历史问题的决议》的定性来写，只写家庭遭遇，不写高层斗争，基调克制，最后落在人性温暖和拨乱反正上。
   - 1989 年：不写。第六部从 1988 年直接跳到 1990 年上交所开业。
   - 二二八、西藏等议题：不涉及。
4. **正向基调**：每一部都以"苦难 → 坚持 → 传承"收尾，符合平台对精品微短剧的导向。
5. **AI 标识**：按《人工智能生成合成内容标识办法》（2025 年 9 月 1 日起施行），每集加显式标识和隐式标识。
6. **备案**：虚构家族框架能降低风险，但仍属于历史题材，上线前要按广电规定备案，建议先咨询省级广电部门。
7. **史实核查**：每集的★事件都要附来源，正式写本前逐条复核。
